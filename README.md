# Botect docs

Source for the Botect API documentation, published with [Mintlify](https://mintlify.com).

- Navigation and theming live in `documentation.json`.
- Pages are `.mdx` files; API reference lives under `endpoints/`.
- Brand assets are in `logo/`.

This repository is consumed as the `docs/` submodule of `botect-web`.

## Local preview

```bash
npm i -g mint
mint dev
```
