---
title: "DELETE /v1/projects/{project}/rules/{rule}"
description: "Delete a custom bot rule from a project."
---

Permanently deletes a [rule](/rules). The rule stops being evaluated immediately.

```http
DELETE https://api.botect.ai/v1/projects/{project}/rules/{rule}
```

## Authentication

Account API token via `Authorization: Bearer <token>`. The project must belong to the token's account, and the rule must belong to the project. See [Authentication](/authentication).

## Path parameters

<ParamField path="project" param-type="integer" required="true">
  The project ID.
</ParamField>

<ParamField path="rule" param-type="integer" required="true">
  The rule ID to delete.
</ParamField>

## Example

<Request show-lines="true" tabs="cURL,JavaScript,Python">
```bash
curl -X DELETE https://api.botect.ai/v1/projects/123/rules/7 \
  -H "Authorization: Bearer YOUR_ACCOUNT_TOKEN"
```

```javascript
await fetch('https://api.botect.ai/v1/projects/123/rules/7', {
  method: 'DELETE',
  headers: { Authorization: `Bearer ${process.env.BOTECT_TOKEN}` },
});
```

```python
import os, requests

requests.delete(
    "https://api.botect.ai/v1/projects/123/rules/7",
    headers={"Authorization": f"Bearer {os.environ['BOTECT_TOKEN']}"},
)
```
</Request>

<Response show-lines="true" tabs="204">
```text
(empty body)
```
</Response>

A successful delete returns `204 No Content`.

## Errors

| Status | `code` | When |
|---|---|---|
| `401` | `UNAUTHENTICATED` | Missing / bad account token |
| `403` | — | Project does not belong to the token's account |
| `404` | — | The rule does not exist or does not belong to the project |
