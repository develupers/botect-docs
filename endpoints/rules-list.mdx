---
title: "GET /v1/projects/{project}/rules"
description: "List a project's custom bot rules in evaluation order."
---

Returns the project's custom [rules](/rules), ordered by `sort_order` ascending — the same order they're evaluated in.

```http
GET https://api.botect.ai/v1/projects/{project}/rules
```

## Authentication

Account API token via `Authorization: Bearer <token>`. The project must belong to the token's account. See [Authentication](/authentication).

## Path parameters

<ParamField path="project" param-type="integer" required="true">
  The project ID.
</ParamField>

## Example

<Request show-lines="true" tabs="cURL,JavaScript,Python">
```bash
curl https://api.botect.ai/v1/projects/123/rules \
  -H "Authorization: Bearer YOUR_ACCOUNT_TOKEN"
```

```javascript
const res = await fetch('https://api.botect.ai/v1/projects/123/rules', {
  headers: { Authorization: `Bearer ${process.env.BOTECT_TOKEN}` },
});
const rules = await res.json();
```

```python
import os, requests

r = requests.get(
    "https://api.botect.ai/v1/projects/123/rules",
    headers={"Authorization": f"Bearer {os.environ['BOTECT_TOKEN']}"},
)
rules = r.json()
```
</Request>

<Response show-lines="true" tabs="200">
```json
[
```

</Response>

## Response fields

Each rule object includes:

<ResponseField name="id" field-type="integer" required="true">The rule ID.</ResponseField>
<ResponseField name="name" field-type="string" required="true">Human-readable label, shown in verdict reasons.</ResponseField>
<ResponseField name="expression_source" field-type="string" required="true">The original expression text (for display/edit). The compiled AST is stored internally.</ResponseField>
<ResponseField name="action" field-type="string" required="true">`block`, `challenge`, `allow`, `log`, or `delay`.</ResponseField>
<ResponseField name="is_active" field-type="boolean" required="true">Whether the rule is evaluated.</ResponseField>
<ResponseField name="sort_order" field-type="integer" required="true">Evaluation order (ascending).</ResponseField>

## Errors

| Status | `code` | When |
|---|---|---|
| `401` | `UNAUTHENTICATED` | Missing / bad account token |
| `403` | — | Project does not belong to the token's account |
